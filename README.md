# Original project code (archive)

The scripts exactly as they were written, before the rewrite on `main`.
Each commit is one phase of the project; its author date is the date the
newest file of that phase was last modified. Result images, spreadsheets and
third-party papers are not included.

See `docs/LEGACY_MAP.md` on `main` for what every file did, which one was the
final version, and where its logic lives now.
